# Unity Game Developer Portfolio

A responsive HTML/CSS/JavaScript portfolio website designed for GitHub Pages.

## Files
- `index.html` — page content and project links
- `style.css` — responsive dark gaming theme
- `script.js` — mobile navigation and placeholder link warning
- `assets/images/` — add your own game screenshots here

## Before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your professional email.
2. Replace `#` placeholder links with your real Google Play, App Store, GitHub, and LinkedIn URLs.
3. Replace or supplement the CSS-made project artwork with real screenshots from your own games.
4. Update the title, About section, and skills so every claim accurately reflects your experience.

## Publish with GitHub Pages
1. Sign in at https://github.com/
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes and open `https://YOUR-USERNAME.github.io/`.

If you instead use a repository with another name, the URL is usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Important
GitHub Pages serves public websites. Do not put passwords, API secrets, private keys, or confidential project files in this repository.
